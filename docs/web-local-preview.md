# Web版のローカル試用

Webブラウザで本体画面と掲示板の閲覧を試すための実験的な構成です。

```powershell
pnpm run build:web
pnpm run preview:web
```

ブラウザで `http://127.0.0.1:4173/view/index.html` を開きます。終了するときはプレビューを実行しているターミナルで `Ctrl+C` を押してください。ソースを変更した場合は再度ビルドが必要です。

板一覧、スレッド一覧、スレッドの取得には、ローカルプレビューに組み込んだ読み取り専用の中継を使います。中継先は対応掲示板に限定し、外部サイトからの要求や範囲外へのリダイレクトを拒否します。プレビューはローカルホストでのみ利用してください。

設定とブックマークはこのWeb版のブラウザ内に保存されます。拡張機能版やTauri版のデータとは共有しません。書き込み、Cookie管理、拡張機能固有の機能、対応掲示板以外への中継は、この試用版では対応していません。

GitHub Pagesは静的ファイルの配信先なので、このローカル専用中継は動作しません。公開するには別途通信方式を設計し、サブパス対応や書き込み・認証の扱いを検討する必要があります。
