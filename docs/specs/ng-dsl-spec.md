# NGルールDSL

## 基本形

動作だけを見出しにし、条件と設定をその中へインデントして書く。
旧形式の `hide body contains:`、トップレベルの `and`、見出し内の `color=…` 等は廃止する。
互換パーサー・移行処理は設けない。保存キーは `ngwords` を使う。

```text
highlight:
  color blue
  label "注目"
  sites "example.com"
  when title contains:
    "chatgpt"
    "claude"
    "gemini"
  when res-count >= 10
  unless title contains "除外"

hide:
  when body regex "(imgur\.com/.+?){15}"

hide:
  when anchor-count >= 10
```

## 条件

- `when 対象 contains "文字列"`：文字列を含む場合に一致する。
- `when 対象 regex "正規表現"`：正規表現に一致する場合に一致する。
- `unless`：条件一覧のOR全体を否定し、どの候補にも一致しない場合に成立する。
- 1つの値は同じ行、複数の値は `contains:` / `regex:` の下へもう1段インデントして並べる。
- 一覧の値同士はOR、ルール内のすべての `when` / `unless` はAND。ルール同士は独立し、記述順に判定する。
- 条件・設定は同じインデント、一覧の値はそれより深い同じインデントで書く。空行と行頭コメントは無視する。
- 数値対象 `res-count` / `reply-count` / `anchor-count` は `>=` / `>` と0以上の整数を同じ行に書く。
- 文字列対象は `all` / `title` / `body` / `name` / `mail` / `id` / `slip` / `url`。

文字列は引用符で囲む。バックスラッシュ自身と引用符を逃がし、改行・CR・タブは `\n` / `\r` / `\t` で表す。
正規表現の `\d` / `\b` 等も記述できる。正規表現は既定で大小文字を無視し、値の後ろの `flags=…` で上書きできる。
通常のcontainsは既存の全角半角・かな・空白・大小文字の正規化を維持する。URLのcontainsはURL文字列をそのまま比較する。

IDなど対象値を取得できない場合は、unlessでも一致しない。不正な正規表現も否定して成立させない。

## 動作・設定

`hide` は設定されたNG表示方式に従う。
`collapse` はクリックで表示できるように折りたたむ。title・url・all・res-countなど一覧で判定できる条件だけならスレ一覧の末尾のグループへまとめる。body・id・nameなどレス固有の条件を含む場合は、レスをその場で折りたたむ。スレ一覧用のルールは、スレを開いたときに全レスを折りたたむことはない。
`highlight` はスレ一覧を強調し、title条件を必要とする。`demote` は廃止し、別名としても受け付けない。
動作とすべての条件を同じ画面で評価できない組み合わせは診断する。例えばレス数と本文を同一ルールでは判定できない。
`warn` は予約語で、実行できないため保存前に診断する。

- `color red` / `color #ffcdd2`：highlightの色。
- `label "注目"`：highlightのラベル。
- `sites "example.com"`：適用するサイト・板。複数なら `sites:` の下に引用文字列を並べる。対象範囲の判定方法は従来と同じ。
- `disabled true`：一時的にルールを無効化する。省略時・falseは有効。

設定の順序は自由で、同じ設定を重複して指定することはできない。color・labelはhighlightでのみ指定できる。
条件や一覧が空のルール、引用符不足、未知の対象・設定、無効な数値・正規表現・flags、インデント違いは行・列付きで診断する。

## 保存・編集・NG追加

「設定 → NG → NGルール」で編集する。文字列置換と同じMonacoエディタと診断表示・記法例を使う。
補完・初期ルール・ID/選択範囲/スレッドタイトルからのNG追加・NG理由の表示もこの構文を使う。
NG・置換の共通エディタは、Enterで現在の行の深さだけを引き継ぐ。コロンによる自動の段増しや貼り付け時の再インデントは行わず、段の変更はTab / Shift+Tabで行う。
エラーのある設定全体は保存せず、最後に保存できた設定を維持する。
解析は後続のルールまで続けて複数の診断を返すが、部分的な保存・適用は行わない。

## 検証

解析・整形の往復、OR・AND・否定、数値境界、適用範囲、色・ラベル、引用符・正規表現・改行を検証する。
既存のID NG集約、追加・保存・再読み込み、右クリック・タイトルからのNG追加を回帰テストする。
E2Eでは新構文の診断・保存抑止・有効な設定の保存・状態復元、除外したIDと通常レスの維持、対象レスの非表示、スレ一覧のハイライトを確認する。
置換DSLのPeggy入口と実行経路も維持する。

## はじめて使うときの例

条件行は半角スペース2つで下げ、文字列は引用符で囲む。

### 複数のIDを非表示にする

次のどれか1つのIDを含むレスが対象。実際のIDに置き換える。一覧は条件行よりさらに半角スペース2つ下げる。

```text
hide:
  when id contains:
    "sample001"
    "sample002"
    "sample003"
```

### unlessだけで指定する

whenは必須ではない。次の例は「保存用」を含まない本文のレスすべてを非表示にする。一部のレスを絞り込む条件ではなく、除外条件に当てはまらない広い範囲へ適用される。

```text
hide:
  unless body contains "保存用"
```

unlessの値が一覧なら、どれかに一致する対象を残し、どれにも一致しない対象へ適用する。IDなど判定する値がない場合は適用しない。

### スレ一覧とレスを折りたたむ

```text
collapse:
  when title contains "定期スレ"

collapse:
  when body contains "宣伝"
```

前者はスレ一覧の末尾へ、後者はレスをその場で折りたたむ。
