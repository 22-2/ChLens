# Web版の架空掲示板デモ

```powershell
pnpm run build:web:demo
pnpm run preview:web
```

`http://127.0.0.1:4173/view/index.html` を開き、「板一覧を開く」→「デモ板一覧」→「お試し」→「デモ掲示板」の順に開きます。板とスレッドは架空のデータで、実際の掲示板の読み取りや書き込みはできません。利用者の設定やお気に入りはブラウザに保存されます。

GitHub Pagesのサブパスを試すには、両コマンドの実行前に `$env:WEB_BASE_PATH = "/repository/"` を指定します。このデモの掲示板データはアプリ内に含まれるため、中継サーバーは必要ありません。公開の操作は含まれません。

同じオリジンのローカル試用版とはブラウザの保存データが共有されます。分けたい場合は、別ポートでプレビューしてください。通常のWeb試用版へ戻すには `pnpm run build:web` で再ビルドします。
