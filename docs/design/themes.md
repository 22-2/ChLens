# テーマの追加

ライト／ダーク／システムの基調とカラースキームは別々に選ぶ。画像出力やエディターは基調を使い、画面の色は基調とカラースキームに応じたCSSトークンで決まる。「OSに合わせる」は選択中のカラースキームを保ったまま基調を切り替える。

組み込みカラースキームを追加する手順は次のとおり。

1. `src/view/browser/theme-registry.ts` の `COLOR_SCHEMES` に一意なIDと設定画面に出す名前を追加する。設定画面と起動時のスクリプトはこの一覧を共有する。
2. `tokens.css` に配色の参照値を定義し、`themes.css` で `data-color-scheme` と `data-theme` に応じたライト・ダーク両方の配色を加える。`midnight` の定義を参照し、必要に応じて意味トークンを上書きする。別ウィンドウのシェルと、ボタンやリンクのコントラストも確認する。
3. 起動前の復元、設定変更、OSの基調変更、別ウィンドウと狭い画面を確認する。`tests/theme-startup.spec.mts` と `use-theme.test.tsx` の対象も追加する。

初回描画のスクリプトはビルド時にレジストリと一緒にバンドルされ、Reactの起動前に配色を適用する。不明な基調はシステム、不明なカラースキームは標準へフォールバックする。旧ライトID `default` と旧テーマID `midnight` は互換性を保って移行する。

この仕組みは開発者が組み込みテーマを追加するための基盤であり、設定画面から任意の色を編集・保存する機能はまだ提供していない。
