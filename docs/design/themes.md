# テーマの追加

テーマは配色のIDとライト／ダークの基調を分ける。画像出力やエディターは基調を使い、画面の色はテーマIDに応じたCSSトークンで決まる。設定の「OSに合わせる」は従来どおり標準のライト／ダークを選ぶ。

組み込みテーマを追加する手順は次のとおり。

1. `src/view/browser/theme-registry.ts` の `THEMES` に一意なID、設定画面に出す名前、`light` または `dark` の基調を追加する。設定画面と起動時のスクリプトはこの一覧を共有する。
2. `tokens.css` に配色の参照値を定義し、`themes.css` に `:root[data-theme-id="ID"]` と対応する `.browser-shell` 向けのルールを加える。`midnight` の定義は既存のダーク基調の参照色を上書きする例。必要に応じて意味トークンを上書きし、ボタンやリンクのコントラストも確認する。
3. 起動前の復元、設定変更、ライト／ダークそれぞれからの切り替え、別ウィンドウと狭い画面を確認する。`tests/theme-startup.spec.mts` と `use-theme.test.tsx` の対象も追加する。

初回描画のスクリプトはビルド時にレジストリと一緒にバンドルされ、Reactの起動前に配色を適用する。IDが不明な場合はOSの基調へフォールバックし、旧ライトID `default` は互換性のためライトとして扱う。

この仕組みは開発者が組み込みテーマを追加するための基盤であり、設定画面から任意の色を編集・保存する機能はまだ提供していない。
